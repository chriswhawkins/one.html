Downloads, execution and limits

SQLite loads the pinned community npm distribution linked by the SQLite project. Pyodide loads its pinned official distribution through jsDelivr. Their supporting assets can be several megabytes. The browser caches downloads; this page does not guarantee offline runtime availability.

Run code you trust. A worker protects UI responsiveness; it is not a security boundary against code that uses browser network or storage APIs. Results are bounded for display. Runtime and execution timings are separate.

An actual transport round trip

Send the same disposable payload to an echo endpoint. Measure complete round-trip latency, then compare a different transport against a compatible server.

The Python helper provides /proofs/echo for WebSocket. WebTransport needs a separate HTTPS/HTTP3 echo endpoint with a trusted certificate.

An echo proves delivery, ordering for this message and measured round-trip time. It does not establish performance under congestion or implement Media over QUIC.

Keep the environment explicit

MQTT needs a broker and a browser client over WebSockets. WebTorrent needs available WebRTC peers. Media over QUIC needs a protocol implementation and relay. Controlled Frame and Direct Sockets require an installed Isolated Web App.

Those integration proofs remain separate from a normal HTML tab. See the roadmap and acceptance tests.
